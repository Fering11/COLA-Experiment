# 实验协议

## 当前可复现范围

`run.py --method cola` 实现论文正文描述的三阶段、七次调用流程：语言分析、领域分析、社交媒体分析；Favor、Against、Neutral 三个单轮辩护；最终裁判。每次请求固定 `temperature=0`。三种分析并行，三种辩护并行；这改变等待时间，不改变输入输出协议。

`--method direct` 是一次请求的直接分类基线。`--method both` 在同一数据和重复次数下运行两者，并以 JSONL 保存逐样本结果和汇总。

## 与作者公开代码的差异

论文正文使用通用领域专家、三个候选立场和 Neutral；作者公开脚本使用目标专属专家、两个辩护者、Irrelevant，并串行处理。此环境按论文正文实现，公开脚本协议应作为单独实验因素，不能混入同一结果表。

## 数据边界

`data/dev15.csv` 是从训练镜像按目标和标签抽取的 15 条开发样本，适合 smoke、提示词和接口验证。它不是官方 SEM16 测试集，运行结果不得写成论文测试集复现。正式复现还需要获得许可的数据、固定模型快照，并按论文重复五次。

## 记录与安全

每条结果完成后立即写入 JSONL。`--trace` 才保存提示词和模型原文；真实推文数据应按许可处理。提供商配置可以来自 Qwen 的 `.env`，但 key 不会被复制到本目录、输出到汇总或写入错误消息。
